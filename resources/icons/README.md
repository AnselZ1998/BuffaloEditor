# Buffalo Logo

Place the original `萌趣水牛品牌图标.png` here as `buffalo_logo.png`.
The referenced ChatGPT `/mnt/data/` file was not available in this Windows session;
no replacement image has been generated.

CMake embeds the PNG at `:/buffalo/icons/buffalo_logo.png` when it exists.
EditorTheme uses that same asset for the application/window icon and brand area.
Reconfigure and rebuild after adding the PNG. For a running build, a loose file
at `<exe directory>/resources/icons/buffalo_logo.png` is also supported on next launch.
